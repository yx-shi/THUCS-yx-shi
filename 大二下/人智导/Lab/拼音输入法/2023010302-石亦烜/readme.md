## 1 架构说明：
按照题目要求实现了基于新浪语料库的二元模型
`sets/`目录下存储预处理后的文件，若正确运行后应包括
* `processed_data/`目录下是语料库预处理的中间结果`month_02%`
* `1_word.json`，单元词频表。格式和OJ上一致
* `2_word.json`，二元词频表。格式和OJ上一致

## 2 三元模型的说明
三元模型未采用输入输出重定向，而是直接通过命令行传参控制输入输出文件

1. 在运行之前先取消`main.py`中对应代码的注释。具体见`main.py`中的代码，将原本二元模型的重定向输入输出代码注释，取消三元模型部分的全部注释

2. 在命令行中使用
	`python main.py [--input INPUT] [--output OUTPUT] [--answer ANSWER]`
	其中：
	* `--input`用于指定输入测试文件，默认值为`./data/input.txt`
	* `--output`用于指定输出文件，默认为`./data/output.txt`
	* `--answer`用于指定答案文件，默认为`./data/answer.txt`

3. 若正常运行，则会在终端输出句准确率和字准确率的结果。输出格式为：
	`整字正确率：xxx`
	`逐字正确率：xxx`
